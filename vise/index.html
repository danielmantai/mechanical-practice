Method: largest candidate rule
  • Sort all tasks by decreasing task time.
  • Keep this list for station assignment.
  • A high-ranked task still needs completed predecessors.
Method: Kilbridge and Wester
  • Draw each task in its earliest possible precedence column.
  • Start with tasks having no predecessors in Column 1.
  • Place each remaining task one column after its latest predecessor.
  • Rank by column, left to right. Within a column, use decreasing task time.
  • Keep scanning into later columns when eligible tasks fit.

Use earliest columns throughout this problem.

Method: fill one station
  1. Start at the top of the priority list.
  2. Find the first unassigned task with all predecessors completed and enough time remaining.
  3. Assign it. Subtract its time from the station's remaining time.
  4. Restart the scan at the top of the list.
  5. Open the next station only when no eligible task fits.

Predecessors may be earlier in the same station. A task that does not fit can be skipped while searching for a smaller eligible task.
