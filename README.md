# Mechanical practice

- [Vise assembly](https://danielmantai.github.io/mechanical-practice/vise/)
- [Reservoir transfer](https://danielmantai.github.io/mechanical-practice/reservoir/)
- [Nozzle supply](https://danielmantai.github.io/mechanical-practice/nozzle/)

Standalone formative exercises with optional methods, worked checks and interpretation questions. Each HTML file includes its diagrams, fonts and scripts for offline use. No accounts or data collection.

Mathematical typesetting uses KaTeX. Its MIT licence is retained inside each page's HTML source. The pump performance curves are supplied educational data.
